Sensors · Skill Hub 7 December 2025

Introduction to Sensors & IR Applications

Used ir sensors to detect objects and built automated alarm systems — connecting sensor input to physical output for the first time.

VenueSkill Hub
DateDec 7, 2025

Overview

This session introduced sensing — the ability for hardware to detect the world around it. Students built circuits where an IR sensor controls an LED and buzzer, creating their first automated system.

Topics

How IR transmitters and receivers work

Digital output readings from sensors

Object detection using IR reflective sensors

Serial Monitor — viewing live sensor data

Activities

LED turns ON automatically when object detected

Buzzer activates based on IR sensor input

Combined LED + buzzer alarm system build

Monitor live sensor readings via Serial Monitor

Photos

Highlights

  • Automation concept clicked the moment the LED responded to a hand
  • Serial Monitor made invisible sensor data visible — a real insight
  • Alarm system activity brought all concepts together
  • Strong logical thinking applied throughout the session
